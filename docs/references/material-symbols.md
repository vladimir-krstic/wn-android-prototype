# Material Symbol control assets

Imported 2026-08-26 for the approved Chats controls, ordinary-sheet cleanup,
and Settings-hub/profile-switching follow-up.
These are Google's **unmodified Android XML** exports, Material Symbols Rounded,
default weight/style, 24 dp. Resource filenames are local aliases; XML artwork,
viewport, tint and any automatic-mirroring metadata remain unchanged. No icon
font/library or runtime download is added.

Google Material Symbols are distributed under the [Apache 2.0 license](material-symbols-LICENSE.txt),
copied from the [official asset repository](https://github.com/google/material-design-icons/blob/master/LICENSE).

The official [Android icon guidance](https://developer.android.com/develop/ui/compose/graphics/images/material)
recommends importing XML from Google Fonts. Each link below is the exact
Google-hosted export used. SHA-256 values pin the downloaded content, since
these public export URLs are not versioned. Other brand/media assets and
unrelated icons are unchanged.

bespoke geometry.
